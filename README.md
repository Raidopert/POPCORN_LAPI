# 🐱🍿 Кошачий попкорнный Беспредел (Cat Popcorn Mayhem)

**8-битный рогалик-аркада про рыжих котиков, куницу и рассыпанный попкорн.**
Собирай попкорн лапкой куницы в стаканчик, уворачивайся от мин-кукурузы,
лови золотые зёрна и открывай новые комнаты — кухня, чердак, подвал, кинотеатр
и другие. Бесконечные уровни, сундучки с перками, мировая таблица лидеров.

- 🎮 **Играть онлайн:** <https://popcorn-lapi.vercel.app>
- 📦 **Репозиторий:** <https://github.com/Raidopert/POPCORN_LAPI>
- 🏷️ **Версия:** pre-alpha 0.0.41 (бейдж виден в главном меню справа внизу)
- 📱 **PWA:** устанавливается на телефон прямо из браузера

### 🌐 Включить мировой лидерборд на проде (5 минут, бесплатно)

1. Создай бесплатный проект на [supabase.com](https://supabase.com)
   (или [neon.tech](https://neon.tech) — любой Postgres).
2. Скопируй строку подключения (Supabase → Settings → Database →
   Connection string, лучше «Transaction pooler», порт 6543).
3. В Vercel → Settings → Environment Variables добавь:
   - `DATABASE_URL` = `postgresql://…` (строка из шага 2)
   - `LEADERBOARD_SECRET` = любая длинная случайная строка
4. Redeploy. Всё — таблицы создадутся сами при первом запросе, топы и
   мировая статистика оживут. Ничего вручную запускать не нужно
   (если захочется тот же эффект локально:
   `DATABASE_URL="postgresql://…" bun run db:push`).

Без базы игра не ломается: ведёт локальный топ и честно пишет,
что мир недоступен (с кнопкой «Повторить»).

## 📥 Установка (Android · iPhone · ПК)

Игра — PWA: ставится как приложение и работает без магазина приложений.

**🤖 Android (Chrome):**
1. Открой <https://popcorn-lapi.vercel.app> в Chrome.
2. Меню ⋮ → **«Установить приложение»** (или «Добавить на главный экран»).
3. Иконка 🐱🍿 появится на рабочем столе — запускай как обычное приложение.

**🍎 iPhone / iPad (Safari):**
1. Открой <https://popcorn-lapi.vercel.app> именно в Safari.
2. Кнопка **«Поделиться»** (квадрат со стрелкой вверх) →
   **«На экран “Домой”»** → **«Добавить»**.
3. Готово — игра запускается с иконки в полный экран.

**💻 Windows / macOS / Linux (Chrome, Edge, Opera):**
1. Открой <https://popcorn-lapi.vercel.app>.
2. В адресной строке справа нажми значок ⊕ **«Установить»**
   (или Меню → «Установить приложение POPCORN PAWS»).
3. Игра появится в меню «Пуск» / Launchpad как отдельное приложение.

сохраняются локально на устройстве.

### 🐳 Docker

```bash
docker compose up --build
# → http://localhost:3000
```

Подробная инструкция (включая опциональную локальную Postgres для
мирового лидерборда) — в [DOCKER.md](./DOCKER.md).

### 🌐 Мировой лидерборд и счётчик запусков

Работает через Neon Postgres: достаточно переменной окружения
`DATABASE_URL` (см. `/api/leaders` и `/api/sessions`). Таблицы
создаются автоматически при первом обращении. Без базы игра честно
переключается в офлайн-режим.
