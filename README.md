# 🐱🍿 Кошачий попкорнный Беспредел (Cat Popcorn Mayhem)

**8-битный рогалик-аркада про рыжих котиков, куницу и рассыпанный попкорн.**
Собирай попкорн лапкой куницы в стаканчик, уворачивайся от мин-кукурузы,
лови золотые зёрна и открывай новые комнаты — кухня, чердак, подвал, кинотеатр
и другие. Бесконечные уровни, сундучки с перками, мировая таблица лидеров.

- 🎮 **Играть онлайн:** <https://popcorn-lapi.vercel.app>
- 📦 **Репозиторий:** <https://github.com/Raidopert/POPCORN_LAPI>
- 🏷️ **Версия:** pre-alpha 0.0.29 (бейдж виден в главном меню справа внизу)
- 📱 **PWA:** устанавливается на телефон прямо из браузера

## 🆕 Что нового в 0.0.29

- 👶 **БОСС «МАЛЫШ» на каждом 10-м уровне** — в зал вламывается ребёнок
  (крупнее воришки-голубя), который рвётся к корзине и выгребает попкорн.
  Трогать малыша лапкой НЕЛЬЗЯ — слетает сердечко!
- 🎯 **Механика тир-арканоид:** быстрый мах лапкой ПИНАЕТ попкорнинки —
  они летят по полю с трением и отскоками, и бивают малыша. У первого
  босса 3 жизни, у каждого следующего на одну больше. Победа — жирный
  бонус очков и монеток, сундучок и следующий уровень.
- ⏱ **Баланс без потолка:** уровень 50 секунд (перк «Кошачьи часы» — 62),
  большая попкорнина живёт 2.4 секунды и убегает быстрее, комбо-множитель
  больше не ограничен ×5, нормы зёрен и состав волн растут без потолка.
  Средний игрок с телефона упрётся в таймер, у скиллового предела нет.

## 📥 Установка (Android · iPhone · ПК)

Игра — PWA: ставится как приложение и работает без магазина приложений.

**🤖 Android (Chrome):**
1. Открой <https://popcorn-lapi.vercel.app> в Chrome.
2. Меню ⋮ → **«Установить приложение»** (или «Добавить на главный экран»).
3. Иконка 🐱🍿 появится на рабочем столе — запускай как обычное приложение.

**🍎 iPhone / iPad (Safari):**
1. Открой <https://popcorn-lapi.vercel.app> именно в Safari.
2. Кнопка **«Поделиться»** (квадрат со стрелкой вверх) →
   **«На экран “Домой”»** → **«Добавить»**.
3. Готово — игра запускается с иконки в полный экран.

**💻 Windows / macOS / Linux (Chrome, Edge, Opera):**
1. Открой <https://popcorn-lapi.vercel.app>.
2. В адресной строке справа нажми значок ⊕ **«Установить»**
   (или Меню → «Установить приложение POPCORN PAWS»).
3. Игра появится в меню «Пуск» / Launchpad как отдельное приложение.

## 🆕 Что нового в 0.0.27–0.0.28

- 🍿 **БОЛЬШАЯ ПОПКОРНИНА** — раз за уровень на поле выкатывается огромный
  карамельно-золотой приз: живёт всего ~3.5 секунды, пытается убежать и
  светится, как ёлка. Успел дотянуться — **+1000 очков сразу и монетки 🪙**.
  Не успел — укатилась. Игрок с телефона чаще всего не успевает, а у
  скиллового потолка нет: чем глубже забег, тем больше шансов.
- 🐾 **Натуральная лапка куницы** — перерисована: милая, но настоящая.
- 👗 **Гардероб +12 предметов** — новая одежда в магазине.
- 💰 **Экономика строже:** вся прокачка апгрейдами теперь стоит
  ≈ 14 400 🪙 (было 3.3 млн) — это ~40–60 обычных забегов; большие
  попкорнины приносят скилловому игроку примерно половину суммы.
- 🎖 **Опыт и древо:** крутая кривая уровней — полное древо больше не
  качается за три забега.

## 🆕 Что нового в 0.0.26

- 🎓 **Туториал первого забега** — 5 коротких подсказок в тёмных облачках
  прямо поверх живой игры: води пальцем → собирай зёрна → берегись мин →
  лови золотое зерно → комбо. Без пауз, только самому первому забегу.
- 🐾 **Ник — после первого забега.** Новичок сразу попадает в игру,
  а имя спрашивается на экране результата («Как записать тебя в историю?»).
- 💾 **Код-бэкап сохранения** — Настройки → Сохранение: экспорт прогресса
  в код-строку (опыт, лапки, ачивки, NANA) и восстановление на любом
  устройстве. Device id остаётся своим — накрутить лидерборд не выйдет.
- 🔗 **OG-превью для ссылок** — красивая карточка с куницей при отправке
  ссылки в Telegram, VK, WhatsApp и соцсети.

## 🚀 Быстрый старт (локально)

```bash
# Node.js 20+ / Bun
bun install        # или npm install
bun run dev        # http://localhost:3000
```

Без базы данных игра полностью работает: лидерборд и статистика
сохраняются локально на устройстве.

### 🐳 Docker

```bash
docker compose up --build
# → http://localhost:3000
```

Подробная инструкция (включая опциональную локальную Postgres для
мирового лидерборда) — в [DOCKER.md](./DOCKER.md).

### 🌐 Мировой лидерборд и счётчик запусков

Работает через Neon Postgres: достаточно переменной окружения
`DATABASE_URL` (см. `/api/leaders` и `/api/sessions`). Таблицы
создаются автоматически при первом обращении. Без базы игра честно
переключается в офлайн-режим.
