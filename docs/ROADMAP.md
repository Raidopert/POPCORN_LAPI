## 2. Сравнение с рынком

Честный разбор соседей по жанру и что мы у них забираем.

| Игра/класс | Сильное | Слабое | Что берём себе |
|---|---|---|---|
| **Suika / «Арбузная игра»** | одна механика, стримабельность, рекордный азарт | без контента быстро надоедает | простота входа у нас уже есть (одна лапка); рекордный дух мирового топа |
| **Hyper-casual (Voodoo-класс)** | мгновенный вход, короткие сессии | выгорание: нет мета-глубины | у нас мета глубже, чем у любого hyper-casual: древо, лут, стиль — подчёркивать в витрине и шерах |
| **Соц-игры VK («Ложки» и др.)** | соц. граф: друзья, подарки, конфедерации | графика обычно беднее | друзья в топе и нативные шеры — самый дешёвый рост для мини-приложения |
| **Idle-кликеры** | ритм сессий, офлайн-прогресс, «прийти за наградой» | нет активного скилла | поездки NANA (t10…t720) уже почти idle; усилить наградой за возвращение |
| **Roguelike-lite (Vampire Survivors-класс)** | билды из перков, «ещё один забег» | сложный порог входа | сундучки с 17 перками уже есть; добавить ежабег-модификаторы комнат — глубина без нового движка |

**Наши дифференциаторы (не терять при развитии):**
1. Живая куница NANA на камере — ни у кого нет такого талисмана.
2. 0+, без пей-ту-вин, юмор и доброта — редкость в жанре.
3. Пиксель-арт, нарисованный процедурно кодом — арт-пайплайн не зависит от художников.
4. Кросс-платформа: VK + web + exe + apk из одного репозитория.

**Наши слепые зоны (закрываются в плане ниже):**
- комнаты чисто косметические — различие между уровнями только в фоне;
- нет удерживающих ритуалов (дейлики/стрики) — возвращаемость держится на «ещё один забег»;
- шеры только через буфер обмена — нативные VK-инструменты не задействованы;
- виды зёрен не раскрывают идею «попкорнный беспредел».

## 3. Заготовки контента (уже в репозитории)

Принцип: контент входит в код **данными** с весом 0 / флагом off,
игровое поведение не меняется до включения. Это позволяет готовить
партии контента заранее и включать точечно.

| Файл | Что заготовлено | Как включается |
|---|---|---|
| `src/lib/game/popcorn-varieties.ts` | 8 будущих видов зёрен с эффектами, редкостью и нотами внедрения | weight > 0 + спрайт в `sprites.ts` + ветка в `spawnWave` |
| `src/lib/game/rooms-future.ts` | 6 комнат + 5 модификаторов (левитация, сладость, тьма, ветер, невесомость) | webp + запись в `ROOMS` + хук модификатора в engine |
| `src/lib/game/style-future.ts` | 15 предметов лавки: партии Хэллоуин/Космос/Зима/Рыцари | PNG/CSS-классы + ключи i18n + запись в каталог `style.ts` |
| `src/lib/game/flags.ts` | 8 флагов фич (varieties, dailies, endless, timeAttack, seasons, collection, friendsLb, roomModifiers) | `isFlagOn('dailies')` в компоненте |
| `scripts/gen-concepts-pixel.py` | процедурный генератор концепт-артов в стиле игры | `python3 scripts/gen-concepts-pixel.py` |
| `public/studio/concepts/` | 5 концепт-листов (виды зёрен, аватары, 3 комнаты) | витрина на `/studio#roadmap` |

## 5. Технические заметки для будущих релизов

1. **Версии/релизы** — `bash scripts/release.sh vX.Y.Z "..."`; помни про гонку exe-сборки с параллельной web-сборкой (перезалив ассета при несовпадении размера).
2. **Прод-PostgreSQL** — любые новые колонки LeaderPlayer делать сразу с DDL в коммите (как `avatar` в 0.0.75).
3. **i18n** — каждый новый ключ = кортеж `[ru,en,de,es]` в `i18n.ts`; не выпускать релиз с пустыми переводами.
4. **Арт-пайплайн** — концепты: `python3 scripts/gen-concepts-pixel.py`; игровые спрайты — процедурные в `sprites.ts`; фото/логотипы — отдельные сессии image-gen.
5. **Флаги** — новое крупное поведение входит только под флагом из `flags.ts`; включение — отдельный коммит/релиз.
6. **Экспорт** — офлайн-сборка `/tmp/export-run.sh` (POPCORN_EXPORT=1, api-stash trap), десктоп NSIS и APK-пайплайн отработаны на 0.0.74/0.0.75.

## 6. Что НЕ делаем (принципы студии)

- Никакого пей-ту-вин: за деньги — только поддержка студии/косметика, если когда-нибудь вообще появится.
- Никакой обидной агрессии в контенте: боссы — смешные, не жестокие.
- Не обещаем даты, которых не знаем: roadmap — направления, а не обещания.
- Не трогаем 0+ и семейность даже ради «трендовых» механик.
