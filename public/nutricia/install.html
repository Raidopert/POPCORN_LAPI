Установить «Рацион»

Приложение для клиентов нутрициолога: дневник питания, меню от врача, контроль веса и чат. Работает на iPhone и Android.

Отсканируйте QR-код
Откройте камеру телефона и наведите на код.
Или нажмите кнопку ниже, чтобы открыть на этом устройстве.
Как установить на телефон
🍎
iPhone / iPad Safari
Только через Safari. Chrome на iOS не умеет ставить PWA.
  1. Откройте приложение в Safari (по QR-коду или кнопкой выше).
  2. Нажмите кнопку «Поделиться» (квадрат со стрелкой вверх, внизу экрана).
  3. Прокрутите и выберите «На экран Домой» (Add to Home Screen).
  4. Нажмите «Добавить» — иконка «Р» появится на главном экране.

Приложение открывается без адресной строки, как нативное. Работает офлайн.

🤖
Android Chrome
Через Chrome — иконка на главном. Или скачайте .apk для установки как обычное приложение.
  1. Откройте приложение в Chrome (по QR-коду или кнопкой выше).
  2. Нажмите меню ⋮ в правом верхнем углу.
  3. Выберите «Установить приложение» (или «Добавить на главный экран»).
  4. Подтвердите — иконка появится в меню приложений.
Скачать .apk (Android)

Если вы хотите установить приложение как обычное (из файла, без браузера), скачайте .apk и откройте его на телефоне.

Файл собран через PWABuilder. При первом открытии Android попросит разрешить установку из неизвестных источников — это нормально.

Если кнопка не работает
.apk ещё не загружен. Врач может собрать его по инструкции ниже.
